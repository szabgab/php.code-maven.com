# Abstract

AI can generate PHP code in seconds, but generating code is not the same as engineering a reliable WordPress plugin.

In this talk, we explore how Spec-Driven Development (SDD) changes the way WordPress plugins can be developed with AI. Using Kiro IDE, we will move beyond ad-hoc prompting and define what our plugin should do before asking AI to implement it.

Starting with an idea for a WordPress plugin, we will transform it into structured requirements, technical design, and implementation tasks. We will then use Kiro's AI capabilities to implement the plugin step by step in PHP while respecting WordPress architecture, hooks, security requirements, coding conventions, and maintainability.

The session includes a practical demonstration showing the complete journey from an initial idea to a working WordPress plugin.
